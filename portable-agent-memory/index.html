portable-agent-memory

One memory contract for durable context across agents, vendors and runs.

Node.jsMarkdownGraph

What it does

Portable Agent Memory is a markdown-first protocol for preserving decisions, facts, source notes, summaries and follow-ups inside ordinary repositories.

  • Agent-readable memory structure with graph JSONL support.
  • Bootstrap instructions for multiple coding agents.
  • Maintenance tooling for durable memory hygiene.
